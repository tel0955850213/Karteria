# Shipaton Submission Checklist

- App: `Karteria: Practice with Proof`
- Brand line: `Practice. Prove. Progress.`
- Primary tracks: Next Gen and Design Award
- Secondary tracks: HAMM, Peace Prize, Build in Public

## Required evidence

- Public MIT source repository.
- Student eligibility material for the master's student entrant.
- App Store link after public launch.
- 1024px icon and current iPhone screenshots.
- A two-minute demo: identity goal, private two-minute rep, evidence contract, safety/preflight boundary, calibrated peer review, 2/3 settlement, Journey result, and RevenueCat Pro boundary.
- RevenueCat integration explanation: public SDK key in the app, server-only grant for Community Pro Pass, no purchasable votes.
- Per-award explanation focused on evidence-based progress, accessibility and motion handling, UGC safeguards, and public build artifacts.

2. Complete feature scope by September 10, beta by September 15, and public App Store availability by September 20.
3. Use only one minimal manual Xcode Cloud Release archive after local verification and a supported Cloud environment are ready.
